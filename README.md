# 👋 Welcome to micromusambi

This repo is where everyone in the team learns how we work: **terminal → git → branch → pull request → review → merge**.

Your first task is waiting for you in the [Issues](../../issues) tab. Look for the one assigned to you.

## How we work

1. Every task is a **GitHub issue**.
2. You never change `main` directly. You make a **branch**, do the work, and open a **pull request (PR)**.
3. Someone else **reviews** the PR. Once it's approved, it gets **merged**, and the issue closes.

## Members

Everyone has a file in [`members/`](members/). Yours shows up there after your first PR is merged.

## Stuck?

Comment on your issue, or ask in the WhatsApp group. Nobody knows this on day one, so ask freely 🙂
